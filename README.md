# 🍔 CraveCraft – Responsive Restaurant Website

CraveCraft is a modern, responsive restaurant website designed to provide users with an attractive and user-friendly food browsing experience.

## 🌐 Live Demo

https://suhail2203.github.io/CraveCraft-website/

## ✨ Features

- Responsive restaurant homepage
- Attractive hero section
- Popular dishes section
- Special offers section
- About Us section
- Customer reviews section
- Interactive menu page with category filters
- Bootstrap modal for special offers
- Contact section
- Responsive navigation and buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Font Awesome
- Google Fonts

## 📂 Project Structure

CraveCraft-website/
- index.html
- style.css
- menu.html
- menu.css
- about.html
- about.css
- README.md

## 🚀 How to Run Locally

1. Clone the repository:

   git clone https://github.com/suhail2203/CraveCraft-website.git

2. Open the project folder in VS Code.

3. Open index.html in your browser, or use the Live Server extension.
